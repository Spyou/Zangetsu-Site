The dozen we’re asked most.

The app is empty — where are the sources?
Zangetsu ships with no sources at all, on purpose. It's a player, not a library — you choose what to add. Open Settings → Sources, pick an ecosystem, and add a repository. We don't host, bundle, recommend or link to any source, and support can't hand you one. See Sources.
Which APK should I download?
Nearly every modern phone wants arm64-v8a. If it won't install, use the universal build. For Android TV use the TV/universal build — many TV boxes are still 32-bit and the arm64-only file will crash on them. See Getting started.
Nothing plays / it just buffers forever
Usually the source, not the app. Try a different source for the same title, then run Settings → Sources → Source health. If a site needs a Cloudflare check, the app opens a browser window — finish it once and it's remembered. See When something won't play.
Is it safe? Is it open source?
Yes — the whole app is open source under GPL-3.0 and every release is built and published on GitHub. There are no ads, no trackers and no account required to watch.
Is there an iPhone version?
Yes — a beta on TestFlight. One catch: CloudStream and Aniyomi/Mihon extensions don't work on iOS, because iOS doesn't allow that kind of plugin loading. You get Zangetsu's own sources, the player, downloads and trackers. See Getting started.
How do I sign in to AniList / MAL / Simkl on my TV?
Typing on a TV is miserable, so you don't. Open Settings → Connections → Connect and scan the QR with your phone — either with the Zangetsu app installed, or straight in your phone's browser if not. See On your TV.
Does it download for offline?
Yes. Tap the download icon on an episode. Streams that arrive in pieces are stitched into a single playable file, so downloads behave like normal videos. You can also pick where they're saved.
How do I update?
The app checks GitHub Releases and offers the update in-app. There's an opt-in beta channel in settings if you want pre-releases. You can always just install a newer APK over the top.
Can I watch on a real TV screen?
Three ways: install it on an Android TV directly, cast to a Chromecast, or use an external player. The TV build has its own D-pad interface — see On your TV.
Manga and novels too?
Yes — there's a reader for both, with its own sources. Same rule: nothing ships bundled, you add what you want.
Does it track what I watch?
Only for you. Progress syncs to your own account if you sign in, and to AniList/MAL/Simkl if you connect them. Incognito mode pauses history, scrobbling and Discord presence while it's on.
Why does a browser window open when I press play?
Some sites sit behind a Cloudflare check, and a few show an ad page. The app opens a real browser view so the check can complete — after that it's remembered. If a source does this every single time, it's a bad source; try another.

01 Getting started

Which file do I want?

Releases carry several APKs because one file for every device would be needlessly large:

  • arm64-v8a — nearly every phone made in the last several years. Start here.
  • armeabi-v7a — older 32-bit devices.
  • universal — works everywhere, bigger file. Use it if you're unsure or the others refuse to install.
  • TV — for Android TV boxes and sticks. Plenty are still 32-bit, so use this rather than the arm64 phone build.
Installing fails or the app closes on launch? You almost certainly have the wrong architecture. Install the universal build instead.

Is it safe?

The app is open source under GPL-3.0 and every release is published on GitHub, so anyone can read the code or build it themselves. No ads, no analytics, no account needed to watch. Android will warn about installing outside the Play Store — that warning is about the install method, not this app in particular.

Updating

Zangetsu checks GitHub Releases and offers new versions inside the app. There's an opt-in beta channel in settings for pre-releases. Installing a newer APK over the top also works and keeps your data.

iPhone and iPad

There's an iOS build on TestFlight. It's a beta, and one limitation is worth knowing before you install it: CloudStream and Aniyomi / Mihon extensions are Android-only. They rely on Android's plugin loading, which iOS doesn't allow. On iOS you get Zangetsu's own JavaScript sources and the built-in player, not the full source ecosystem.

So if a guide here mentions a CloudStream or Aniyomi repository, that part is for Android. Everything else — the player, downloads, trackers, your list — works the same.

First run

Opening the app the first time walks you through a short setup. There's nothing to sign up for — an account is optional and only exists to sync your list across devices. When it finishes you land on an empty home screen, because no sources are installed yet. That's the next step.

02 Sources

This is the part that confuses people most, so plainly: Zangetsu ships with nothing. Fresh install, no sources, empty home screen. That's deliberate.

We don't host, bundle, recommend or link to any source — not in the app, not on this site, and not in support. Zangetsu is a player. What you point it at is your decision and your responsibility.

What a "source" actually is

A source is a small plugin that knows how to search one website and find video for a title. Sources come from repositories — a URL that lists plugins the app can install. Add a repository, install sources from it, and the app can then search them.

The ecosystems

Zangetsu understands several plugin formats, so extensions written for other apps work here too:

  • Zangetsu — the app's own lightweight JavaScript sources.
  • CloudStream — .cs3 extensions.
  • Aniyomi / Mihon — installed as Android extension packages. Aniyomi covers anime, Mihon covers manga.
  • LNReader — plugins for light novels.

Adding one

Settings → Sources → pick an ecosystem → Add repository

Paste the repository URL, let it load, then install the sources you want. They show up in the source switcher at the top of the home screen. Installed sources can be updated from the same screen when the author publishes a new version.

Anime, movies, manga, novels

The app has separate modes for watching and reading, and the source switcher only offers sources that fit what you're doing. If a mode looks empty, you haven't added a source for that mode yet — the home screen will say so and point you at the right screen.

03 Watching something

Find it

Search from the magnifying glass in the bar at the bottom. Results are grouped by source, so you can see at a glance who has the title. The chip at the top of the home screen switches which source you're browsing.

Play it

Open a title, pick an episode, and it starts on the first server that responds. If that one is poor, open the sources sheet in the player and pick another — your choice is remembered for that title.

In the player you get speed, subtitles and their styling, quality where the stream offers it, and gestures for seek, brightness and volume. Progress is saved automatically, so Continue watching on the home screen picks up where you stopped.

Save it for offline

Tap the download icon on an episode, or use the batch button on the episode list to grab several at once. Streams that arrive in pieces are stitched into a single playable file, so downloads behave like ordinary videos — including seeking. Downloads live under the Downloads section, and you can choose the folder in settings.

04 When something won't play

Almost always the source rather than the app. Sites break, move domain, add bot protection or simply go down — and a source written for last month's layout stops working. Work through these in order.

1 — Try a different source

Open the same title from another source. If a second one plays, the first is broken and there's nothing to fix on your end.

2 — Check source health

Settings → Sources → Source health

This tests your installed sources and marks the dead ones. Search puts healthy sources first and skips ones that just failed, so clearing out dead sources genuinely speeds things up.

3 — Update your sources

When a site changes, its source usually gets fixed within days. The sources screen shows a badge when updates are available.

4 — Cloudflare and ad pages

Some sites sit behind a "checking your browser" screen. The app opens a real browser view so you can complete it — do it once and the result is remembered. A few sources also open an ad page in your browser when resolving a link; that's the source's behaviour, not the app's.

Slow to start, or stalls part-way

  • Some streams carry a dozen or more audio languages, which can make startup slow. Recent versions handle these much better — make sure you're up to date.
  • Raise the buffer under Settings → Playback if playback dips on a weak connection.
  • If one server stalls, open the sources sheet in the player and pick a different one.
  • Still stuck? Try an external player from the player menu.

Quality looks wrong

The quality button lists the resolutions inside the stream you're playing. If a source only offers one file per quality, they appear as separate servers in the sources sheet instead. A source that reports nothing shows no quality button — that's honest rather than broken.

05 On your TV

Installing

Use the TV build from releases — many TV boxes and sticks are still 32-bit, and the arm64 phone build will crash on them. Sideload it however you normally do; the app detects the TV and switches to a D-pad interface automatically.

Getting around

Everything is built for a remote — arrow keys to move, OK to select, Back to go up. Holding OK on a poster opens its quick menu, the same as a long-press on a phone.

Signing in without typing

Typing on a TV is painful, so you scan a code instead.

Settings → Connections → Connect

Two QR codes appear:

  • Have the app? — scan with a phone that has Zangetsu installed. The phone opens, you approve, and the TV is signed in.
  • No app? — scan with any phone's camera. It opens a web page where you sign in with your browser, and the TV picks it up.

The same flow connects AniList, MyAnimeList and Simkl to the TV.

Sources on TV

Sources work exactly as they do on a phone, and the screens are the same ones adapted for a remote. Adding a repository means typing a URL, which is the one genuinely awkward moment — if you use the app on a phone as well, it's easier to get set up there first.

Casting instead

If you'd rather not install anything on the TV, cast from your phone to a Chromecast. Some streams need particular headers to play, which the app handles by serving them through the phone — so keep the phone awake and on the same network while casting.
