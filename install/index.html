Install & set up

Install the app, tap Get Started, and Zangetsu sets up its sources for you — anime, movies and TV.

Two steps

Install

Step 01 · Download

Download the app

Tap Download APK and pick arm64 — it fits nearly every phone from the last several years (or universal if you're unsure). Once it downloads, tap the file to install. An .apk is how Android apps install outside the Play Store.

Download APK latest
Step 02 · Set up

Open & tap Get Started

Open Zangetsu and tap Get Started. It downloads the official source catalog and shows “You're all set!” — your sources (anime, movies and TV) are installed, no manual setup.

Prefer to explore first? Tap Skip for now — you can add sources any time in Settings → Providers.

Optional · for even more

Add more sources

The official catalog is installed at setup. Want even more? In the app go to Profile → Providers, open an ecosystem, tap Add repo, then Install the sources you want.

How to watch

Find something

Scroll the rows on Home, or tap Search at the bottom for a specific title.

Watch it

Open a title and tap Play. For a series, pick an episode first.

If it won't load

Tap the source name at the top and switch — some go down temporarily.

Save for offline

On a title, tap Download — watch it later under Downloads.

Troubleshooting

Quick fixes

“App not installed”

Usually an old copy is in the way, or the download was incomplete. Uninstall any old Zangetsu, re-download fully, and pick arm64 (or universal if unsure).

A title won't play

Tap the source name at the top and switch, or pick a different server. If a whole source looks dead, check Settings → Source health or add another.

Sources won't download at setup

Check your internet and tap Try Again. Some ISPs block GitHub — turn on Settings → DNS (Cloudflare) and retry, or Skip for now and add sources later.

Do I need an account?

No. Everything works without one. Sign in only to sync your list and history across devices — Settings → Connections.
